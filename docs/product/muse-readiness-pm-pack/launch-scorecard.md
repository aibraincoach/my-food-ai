**DRAFT / ALL UNRUN.** These thresholds are recommendations for PM calibration, not measured My Food AI results and not Meta's original scorecard. Sample sizes are proposed evaluation fixtures, not customer outreach authorization. No test, long run or production mutation is authorized by this pack. `UNRUN` is not green and not proof of failure.

## Gate semantics
- `invariant`: any observed privacy breach, unauthorized action, silent loss or false certainty blocks the relevant release; 100% means **zero failures in the tested sample**, never proof of zero population risk.
- `core`: user-experience gate for the supported release slice. PM must adopt thresholds and sample/device coverage before use.
- `pilot`: proposed activation learning; test with approved participants only. Small-cohort percentages are coarse, not a population estimate.
- `optional`: not a blocker for launching a product that excludes this capability. Sharing may stay off; an enabled sharing flow must pass privacy gates.
- All counts include failures and timeouts in the denominator; never retry-select a green result. Record exact build/model/prompt/fixture versions and per-device/network outcomes.
- A release is ready only when all **applicable adopted** core/invariant rows have valid evidence at the release candidate, each unknown is resolved or the capability is explicitly out of scope, and normal project review/authorization is satisfied. Do not claim the whole product ready from a composite average.
- Keep deterministic arithmetic separate from model identification and visual portion-estimate validation. Weighed/label fixtures supply ground truth; visual annotations do not.
- For long observations/soaks the repository requires written PM **and** owner confirmation; none is supplied here. Such runs are flagged/skipped, not silently started.
