## Long runs, long waits, long collections

If there is ever a question about whether to do a long run, a long wait, a long collection of data, an observation window, a soak, a sampler, or anything that takes hours, do all of these:
1. Flag it at once, in capital letters, as the first line of your report: "LONG RUN FLAGGED AND SKIPPED: <what it is, how many hours>".
2. Skip it completely. Do not start it, do not leave it running, and do not hold any report, merge or handover for it.
3. Start it only after you have a written confirmation from the PM and a written confirmation from the owner that it is absolutely necessary. One confirmation is not enough. A plan that contains it is not a confirmation.
4. If you are unsure whether something counts, it counts. Flag it and skip it.
